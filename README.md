## 🏆 Research & Achievements

### 📜 Published Indian Patent Application

**Multi-Hazard Prediction System Using Adaptive Terrain Graph**

<blockquote>
  <b>Application Number:</b> 202641065384

  <b>Publication:</b> June 2026

  <b>Filed:</b> April 2026

  <b>Institution:</b> Vellore Institute of Technology

  <b>Domain:</b> Geospatial AI · Environmental Digital Twins · Computational Hydrology
</blockquote>

Developed a software-based environmental Digital Twin architecture designed to model interconnected flood inundation and landslide susceptibility using adaptive terrain graph representations.

The system explores efficient spatial computation through adaptive quadtree terrain meshes and has been evaluated across geological regions including the Western Ghats, Assam and Uttarakhand.

**Reported engineering results:**
- 65% reduction in raster processing overhead.
- Sub-second hazard contour generation in evaluated scenarios.

**Explore the work:**

- [📄 Patent Application Document](https://github.com/srikar123s/srikar123s/blob/main/multihazard.pdf)
- [💻 Implementation Repository](https://github.com/srikar123s/Multi-Hazard-Prediction-System)
